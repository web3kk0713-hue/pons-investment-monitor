# 投资状态判定规则

## 基本面配置

同时满足：

1. 价值捕获改善：PONS 可归因回购/销毁发生，7日协议收入相对前7日改善，且30日趋势不恶化；若 V2 增长但 PONS 捕获为零，不通过。
2. 留存改善：creator 复发率和毕业项目 D7 留存均有可比前值并改善，毕业率不低于阈值。
3. 安全改善：Owner/operator/费率策略没有未解释变化，无开放的严重审计问题，地区限制未扩大。
4. 流动性改善：正负2%可执行深度改善、Top10成交集中度不恶化，资金费率不过热。
5. 关键指标覆盖率至少 85%，快照不超过 30 小时。

## 事件驱动观察

没有重大红旗，但至少一个维度未改善或缺关键数据。收入和热度可以很高，仍不代表 PONS 已建立可持续价值捕获。

## 风险降级

命中任一硬红旗：关键权限地址未预期变化、合约/安全重大事件、主要市场不可交易、正负2%深度低于阈值并显著下降、数据超过 72 小时仍未更新，或已验证价值捕获机制被取消。
